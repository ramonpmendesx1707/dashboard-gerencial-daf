# Instrução pronta para outra IA

Publique este projeto em um repositório da minha conta GitHub. Nome sugerido: dashboard-gerencial. Utilize README.md como página inicial. Confirme conta e visibilidade caso ainda não tenham sido informadas.

1. Preserve código, documentação, public, build, scripts, drizzle, package.json, pnpm-lock.yaml e pnpm-workspace.yaml.
2. Não envie node_modules, dist, caches, .wrangler, arquivos de ambiente, cookies, credenciais, banco, dados reais ou .sites-runtime. Confira .gitignore.
3. Instale com pnpm install --frozen-lockfile. Execute TypeScript, node scripts/test-operational.mjs e build. Informe impedimentos sem alegar verificações que não ocorreram.
4. Preserve a identidade independente. Não reintroduza logos DAF/Barigui, Tendências ou Pensando fora da caixa. Leituras da Diretoria são descritivas e exclusivas desse perfil na demonstração.
5. Documente que a alternância de perfis é uma simulação de UX; autorização real depende de implementação no backend.
6. Não publique senhas nem invente uma licença. Para hospedagem nova, siga DEPLOY_MANUAL.md com credenciais e D1 próprios.
7. Este pedido é para publicar o repositório; só implante hospedagem se eu solicitar. GitHub Pages não atende ao login e ao D1.
8. Entregue o link do repositório e as etapas restantes para hospedagem.

Descrição sugerida: Portal independente de acompanhamento comercial com indicadores expansíveis, clientes, mapa municipal e relatórios por perfil demonstrativo.
